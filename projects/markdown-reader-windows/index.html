Overview

Markdown Reader for Windows is a dedicated desktop application engineered in Rust for writers, developers, and researchers who require an instantaneous, offline Markdown reading experience without the overhead of heavy text editors or browser tabs.

Originally inspired by the open-source project md-reader, this project takes the clean reading interface and reimagines it as a native Windows desktop client with low memory consumption and fast rendering.

Key Features

  • Multi-Source & Format Support: Directly opens .md, .markdown, .mkd, and .mdx local files, as well as remote Markdown via https:// URLs.
  • Blazing Speed & Low Footprint: Engineered with Tauri and Rust to ensure instant launch times and minimal RAM consumption without heavy Electron bloat.
  • Interactive Diagrams & Math:
    • Full Mermaid support (flowcharts, sequence diagrams, state models) with dynamic theme synchronization.
    • Graphviz DOT block rendering.
    • KaTeX math formulas with LaTeX formatting.
  • Instant File Watching & Live Reload: Automatically detects updates when files are modified externally in code editors (VS Code, Notepad++, Vim) and refreshes without losing scroll position.
  • Rich Document Formatting: GitHub-Flavored Markdown (GFM) tables, task lists, footnotes, abbreviations, definition lists, alerts, and syntax highlighting for 50+ programming languages.
  • Interactive Reading Tools:
    • Sidebar Table of Contents (TOC) with active scroll tracking.
    • Anchored modal-style image viewer to zoom into diagrams and screenshots.
    • One-click code block copy button with visual clipboard confirmation.
    • Centered reading mode and raw Markdown source toggle.
  • Clean Reading Themes: Toggle between high-contrast light mode, dark mode, and auto system theme matching.

Installation Guide

  1. Download the installer executable using the button above.
  2. Run the installer and follow the setup prompt to install the application.
  3. Right-click any .md or .markdown file in Windows File Explorer, choose Open with, and select Markdown Reader to set it as your default viewer.
