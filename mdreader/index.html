A dedicated, distraction-free desktop application engineered in Rust. View, preview, and navigate your Markdown files with instant live auto-reload and an automated table of contents outline.

Engineered for Developers & Technical Writers

A complete Markdown reading workstation combining native Tauri speed with rich syntax, diagramming, and distraction-free reading tools.

📁

Multi-Format & URL Support

Opens local .md, .markdown, .mkd, and .mdx files, plus remote documents directly from https:// URLs.

📊

Mermaid & Graphviz Diagrams

Full in-situ rendering of Mermaid flowcharts, sequence diagrams, class models, and Graphviz DOT graph blocks with automatic theme synchronization.

∑

KaTeX Math & Rich GFM

Typeset complex math equations with KaTeX. Supports footnotes, definition lists, task checkboxes, superscript/subscript, alerts, and multi-markdown tables.

🔄

Live Hot Reload on Save

Continuously watches open files. When you save changes in VS Code or any text editor, the viewer instantly refreshes without losing your scroll position.

📑

Dynamic Table of Contents

Collapsible sidebar automatically parses document headings into an interactive outline with active scroll-tracking anchors and smooth jumping.

🔍

Modal Image Zoom

Click any screenshot, architectural diagram, or figure to open a smooth zoom overlay anchored to its origin position for close inspection.

📋

One-Click Code Copy

Every code snippet is styled with syntax highlighting across dozens of languages and features a dedicated clipboard copy button with feedback.

🌓

Adaptive Themes & Reading Modes

Switch effortlessly between light, dark, and auto system themes. Toggle between centered reading width and full-width, or switch to raw source view.

⚡

Native Rust & Svelte Architecture

Packaged with Tauri and Svelte for rapid startup, tiny 5.1 MB setup footprint, and minimal memory usage without the baggage of heavy Electron browsers.
